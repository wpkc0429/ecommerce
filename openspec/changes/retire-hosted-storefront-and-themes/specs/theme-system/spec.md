**Reason**: 託管渲染、主題與 site／網域路由已由使用者核准移除（2026-11-24，見 ADR 0001 修正與本 change 的 design）。

**Migration**: 頁面與全域內容的 schema 已在本 change 的階段 1 搬到每店的 `content_schemas`；商家以 `X-Publishable-Key` 解析，不再有 Host／site 對應。
