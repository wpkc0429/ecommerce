## ADDED Requirements

### Requirement: 商品編輯器提供副標欄位

後台商品編輯器 MUST 提供 `subtitle` 輸入框（標籤註明可用於英文品名），載入時回顯目前值，儲存時隨既有的完整商品酬載一併送出；商品列表 SHOULD 在標題下方顯示副標。

#### Scenario: 編輯副標
- **WHEN** 商家在商品編輯器輸入副標並儲存，重新開啟該商品
- **THEN** 副標欄位顯示剛才儲存的值，且 SKU 與分類未受影響

### Requirement: 分類視圖提供商品排序

分類視圖 MUST 為每個分類提供「商品排序」介面：列出直接關聯商品（含草稿標示），可上下移動，儲存時送出完整排列。介面 MUST 說明「子分類的商品會排在直接成員之後，依建立順序」。可見性為 `category.edit`。

#### Scenario: 調整本季新品順序
- **WHEN** 商家在「本季新品」把最後一個商品移到第一並儲存
- **THEN** 重新開啟排序介面時順序保持
