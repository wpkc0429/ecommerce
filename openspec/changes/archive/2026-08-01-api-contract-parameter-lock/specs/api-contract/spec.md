## MODIFIED Requirements

### Requirement: v1 表面受鎖檔保護，移除任何公開承諾必須是明示動作

系統 MUST 維護一份版本控制中的 v1 表面鎖檔，記錄 v1 已對外承諾的每一項可機械列舉的公開事實，至少涵蓋：

- **每一條路由**（HTTP 方法 ＋ 路徑樣板）；
- **每一個具名資料結構的公開回應鍵**；
- **每一條端點所接受的每一個請求參數**，記錄其名稱、所在位置（標頭／查詢字串／路徑）、以及**是否可以省略**；
- **每一條端點所承諾回應的標頭**（含其所屬狀態碼）。

請求參數與回應標頭 MUST 以**端點為單位**記錄，MUST NOT 僅以契約文件中的可重用元件為單位記錄——消費端依賴的承諾是「這條端點接受該參數」，而非「文件中存在某個可重用元件」。因此，將某條端點對共用參數元件的引用移除、而保留元件定義本身，MUST 導致檢查失敗。

鎖檔 MUST 同時涵蓋以共用元件表達與就地展開表達的參數與回應標頭；解析共用元件引用時，若引用無法解析，系統 MUST 失敗並指出該引用，MUST NOT 靜默略過（否則重新產生鎖檔時會安靜地產出一份不完整的鎖）。

系統 MUST 具備一項自動化檢查，驗證鎖檔中的**每一行**在契約文件中仍然存在。新增路由、欄位、參數或回應標頭 MUST NOT 導致該檢查失敗（additive 變更自由）；移除任何一項 MUST 導致該檢查失敗。

**必填方向性**：將某個請求參數由選填改為必填 MUST 導致檢查失敗（收緊 ＝ 破壞性）；由必填改為選填 MUST NOT 導致檢查失敗（放寬 ＝ additive）。此方向性 MUST 由鎖檔所記錄的事實本身表達，MUST NOT 藉由讓檢查邏輯對不同種類的行套用不同比較規則來達成——檢查的判定規則 MUST 維持為單一且可由人在審查時原地驗證的形式（「鎖檔的每一行今天仍存在於契約中」）。

**粒度邊界**：鎖檔 MUST NOT 記錄參數的型別、格式、長度或值域約束、敘述文字與範例值。修改參數的敘述、補充範例、或放寬其值域約束 MUST NOT 導致檢查失敗。此邊界為刻意取捨：系統 MUST NOT 宣稱鎖檔能擋住約束的收緊，該部分的防線是變更審查而非本檢查。

修復該失敗的唯一方式 MUST 是人工從鎖檔中刪除對應行——該刪除動作 MUST 在版本控制的差異中可見且可審查。

鎖檔 MUST NOT 依賴 git 歷史或任何滑動的比較基準點。

檢查失敗時 MUST 逐項列出消失的行，且該行 MUST 足以指出是哪一條端點的哪一個承諾。

#### Scenario: 純新增不觸發失敗

- **WHEN** 契約新增一條路由與若干新回應鍵，且未移除任何既有項目
- **THEN** 表面鎖檢查通過

#### Scenario: 靜默移除公開回應鍵

- **WHEN** 契約移除一個已在鎖檔中的公開回應鍵
- **THEN** 表面鎖檢查失敗，並指出缺少的那一項

#### Scenario: 靜默移除請求標頭參數

- **WHEN** 契約從某條端點移除一個已在鎖檔中的請求標頭參數
- **THEN** 表面鎖檢查失敗，並指出是哪一條端點的哪一個標頭消失了

#### Scenario: 選填參數被改成必填

- **WHEN** 契約將某個原本可省略的請求參數改為必填
- **THEN** 表面鎖檢查失敗，並指出該端點的該參數不再可省略

#### Scenario: 必填參數被放寬為選填

- **WHEN** 契約將某個原本必填的請求參數改為選填，且未移除任何參數
- **THEN** 表面鎖檢查通過（放寬是 additive 變更）

#### Scenario: 移除端點對共用參數元件的引用

- **WHEN** 契約從某條端點刪除對共用參數元件的引用，但保留該元件的定義
- **THEN** 表面鎖檢查失敗（承諾是以端點為單位做出的）

#### Scenario: 移除已承諾的回應標頭

- **WHEN** 契約移除某條端點在某個狀態碼下承諾的回應標頭
- **THEN** 表面鎖檢查失敗，並指出該端點、該狀態碼與該標頭

#### Scenario: 無害的敘述修改不觸發失敗

- **WHEN** 契約只修改某個請求參數的敘述文字或範例值，未改變其名稱、位置與是否必填
- **THEN** 表面鎖檢查通過

#### Scenario: 共用元件引用無法解析

- **WHEN** 契約中某個參數或回應的共用元件引用指向不存在的元件
- **THEN** 檢查失敗並指出該引用，而非把該項目視為不存在

#### Scenario: 破壞 v1 必須留下可審查的痕跡

- **WHEN** 開發者確實需要移除一個 v1 的公開承諾
- **THEN** 除了修改契約，還必須從鎖檔刪除對應行，該刪除出現在程式碼審查的差異中
