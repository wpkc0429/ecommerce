## ADDED Requirements

### Requirement: 生產組裝的每一項相依都必須被接上，且由 CI 內的檢查證明

系統的組裝根（將基礎設施、領域服務與 HTTP 層相依接在一起的那一段程式碼）MUST 有一項自動化檢查，執行**該段程式碼本身**（而非任何代表它、鏡像它或重建它的替代品），並斷言其產出的相依結構中，每一個宣告的相依皆已被賦值。

該斷言 MUST 為遞迴的：不僅是頂層的相依欄位，各 handler 所宣告的相依欄位、以及其下由本系統擁有之型別的相依欄位，皆 MUST 非空。一個未被賦值的巢狀相依 MUST NOT 因為「路由仍然掛得上」而被視為通過。

該檢查 MUST 由持續整合流程自動執行。若某個相依在生產環境中確實可以合法為空，MUST 以明示登記的方式豁免，且該登記 MUST 附帶理由；系統 MUST NOT 以放寬檢查（例如整體略過某一層）的方式處理個別豁免。

檢查失敗時 MUST 指名是哪一條相依路徑未被賦值。

#### Scenario: 新增 handler 而未在組裝根接上

- **WHEN** HTTP 層相依結構新增一個 handler 欄位，且組裝根未賦值給它
- **THEN** 接線完整性檢查失敗並指名該欄位（若不檢查，該 handler 的全部路由在真實伺服器上回 404，而所有既有測試維持通過）

#### Scenario: 巢狀相依未接上

- **WHEN** 組裝根建立了某個服務，但未將它賦值給使用它的 handler 之相依欄位
- **THEN** 接線完整性檢查失敗並指名該相依路徑（路由數量不變，因此路由層的檢查無法發現它）

#### Scenario: 檢查執行的是真正的組裝程式碼

- **WHEN** 檢查執行
- **THEN** 它呼叫的是服務啟動時所執行的同一段組裝程式碼，MUST NOT 是為測試而另外撰寫的等價實作

### Requirement: 領域事件的訂閱集合受鎖定，新增與移除皆須明示

系統 MUST 具備一項自動化檢查，列舉真實組裝完成的事件分派器所持有的訂閱者集合，並與一份版本控制中的預期集合做**相等**比對。

移除任一訂閱 MUST 導致檢查失敗。**新增任一訂閱亦 MUST 導致檢查失敗**——新增一個訂閱者即新增一條跨模組的事件鏈，它 MUST 迫使作者明示地更新預期集合，並在該時點決定端到端覆蓋是否需要一併補上。

該檢查 MUST 斷言系統中只存在**單一**事件分派器實例：所有發佈端與訂閱端 MUST 持有同一個實例。持有不同實例 MUST 導致檢查失敗（訂閱集合正確但發佈者對著另一個分派器發佈，其效果與未訂閱相同）。

訂閱者的識別方式 MUST 對「與訂閱無關的程式碼變動」保持穩定，MUST NOT 因為同一檔案中新增了不相關的程式碼而失敗——防腐檢查的假警報會導致它被忽略，其代價高於它擋住的東西。

該檢查 MUST 由持續整合流程自動執行，MUST NOT 僅由不在持續整合流程內的端到端測試提供。

#### Scenario: 移除一個事件訂閱

- **WHEN** 組裝根移除某個領域服務的事件訂閱
- **THEN** 訂閱集合檢查失敗並指出缺少哪一個訂閱者（該訂閱移除後，事件仍會發佈、所有既有測試仍通過，而真實伺服器靜默地不再產生該效果）

#### Scenario: 新增一個事件訂閱

- **WHEN** 組裝根新增一個新的事件訂閱者，且未更新預期集合
- **THEN** 訂閱集合檢查失敗，指出多出的訂閱者

#### Scenario: 出現第二個事件分派器

- **WHEN** 某個子系統改為持有自己新建的事件分派器
- **THEN** 單一實例斷言失敗

#### Scenario: 不相關的程式碼變動不觸發失敗

- **WHEN** 組裝根新增一段與事件訂閱無關的程式碼
- **THEN** 訂閱集合檢查通過

### Requirement: 端到端測試不得是任何組裝事實的唯一防線

任何「接線是否成立」的事實——相依是否被賦值、事件訂閱是否存在——MUST 至少有一項在持續整合流程內執行的檢查守著。系統 MUST NOT 以不在持續整合流程內的端到端測試作為該類事實的唯一覆蓋。

端到端測試 MUST 保留其對**行為**的覆蓋（接上之後整條鏈的計算結果是否正確）。此需求 MUST NOT 被解讀為端到端覆蓋可以縮減。

#### Scenario: 事件鏈斷裂在持續整合流程內被發現

- **WHEN** 事件訂閱被移除且僅執行持續整合流程所執行的測試（不執行端到端測試）
- **THEN** 有檢查失敗

#### Scenario: 端到端覆蓋維持不變

- **WHEN** 本能力的檢查全部通過
- **THEN** 既有端到端測試對事件鏈行為（金額、點數數量、等級升降、重送冪等）的斷言 MUST 仍然存在且仍然執行
